# CLI Task Tracker

Небольшой консольный таск-трекер, написанный на Go.

Проект позволяет управлять списком задач через командную строку. Все задачи сохраняются в JSON-файл, поэтому после завершения программы данные не теряются.

## Возможности

- Добавление новой задачи
- Изменение описания задачи
- Удаление задачи
- Изменение статуса задачи:
  - `todo`
  - `in progress`
  - `done`
- Просмотр всех задач
- Фильтрация задач по статусу
- Автоматическое сохранение списка задач в `data.json`

## Используемые технологии

- Go
- Стандартная библиотека Go
- JSON для хранения данных

## Доступные команды

- `help` — вывести список доступных команд.
- `add <описание>` — добавить новую задачу.
- `update <id> <описание>` — изменить описание задачи.
- `delete <id>` — удалить задачу.
- `mark-todo <id>` — изменить статус задачи на `todo`.
- `mark-in-progress <id>` — изменить статус задачи на `in progress`.
- `mark-done <id>` — изменить статус задачи на `done`.
- `list` — вывести список всех задач.
- `list-todo` — вывести задачи со статусом `todo`.
- `list-in-progress` — вывести задачи со статусом `in progress`.
- `list-done` — вывести задачи со статусом `done`.
- `clear` — удалить все задачи.
- `end` — завершить работу программы.
